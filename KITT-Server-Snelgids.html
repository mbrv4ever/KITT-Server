KITT-Server

Snelgids · Het hoofdkwartier op je pc: de motor achter DraveKITT Mobile.

1. Wat is het?

KITT-Server draait op je eigen pc en doet het zware werk voor de telefoon-app DraveKITT Mobile. Hij gebruikt het grote taalmodel, zoekt online en haalt het echte weer op. Je telefoon stuurt een vraag, de pc rekent en stuurt het antwoord en de KITT-stem terug. De server gebruikt het model en de instellingen van je DraveKITT-installatie op de pc.

2. Starten

  1. Start eerst minstens één keer de pc-app DraveKITT, zodat er een taalmodel is.
  2. Pak de download-zip uit en zet de map KITT-Server naast de map DraveKITT.
  3. Dubbelklik op DraveKITT-Server.exe. Er komt een drakenicoon rechtsonder bij de klok.
  4. Wacht tot het model geladen is. Rechtsklik op het icoon: bovenaan staat dan het adres, bijvoorbeeld http://192.168.x.x:8000.
  5. Vraagt Windows Firewall om toestemming? Sta toegang toe voor privénetwerken.
  6. Open DraveKITT Mobile op je telefoon, tik op 'Instellen' en 'Zoek hoofdkwartier (automatisch)', of vul het adres in. Tik op 'Opslaan'.

3. Menu van het drakenicoon (rechtsklik)

Status / AdresBovenste regel. Eerst de status (zoals 'Model laden...'), daarna het adres.
Open KITT (deze pc)Opent KITT in de browser op deze pc.
Adres kopierenKopieert het adres, zodat je het kunt plakken of overtypen.
AfsluitenStopt de server. De telefoon kan KITT dan niet meer bereiken.

4. Samenwerken met DraveKITT Mobile

Wat doet de server?Hij is de motor: taalmodel, online zoeken, weer en de KITT-stem.
AdresDe server luistert op poort 8000, bijvoorbeeld http://192.168.x.x:8000.
Automatisch vindenDe telefoon roept over het wifi-netwerk (poort 8001). De server antwoordt met zijn adres.
Vraag en antwoordDe telefoon stuurt de vraag; de server stuurt het antwoord terug.
StemDe telefoon vraagt de server om het antwoord in te spreken. Heeft de server geen stem, dan spreekt de telefoon zelf.
Server uitDe telefoon zegt dat hij het hoofdkwartier niet kan bereiken en antwoordt zelf kort.

5. KITT in de browser

Adres openen in een browserOp het adres van de server staat ook een KITT-webpagina met dezelfde knoppen.
InstellenKies de KITT-stem, de spreeksnelheid en eventueel een wachtwoord. Met 'Test stem' hoor je hem.
Vraag / SpreekTyp en druk op Vraag of Enter. Spreek werkt alleen via een beveiligde (https) verbinding.

6. Console-versie

Start-KITT-server.batStart de server in een venster in plaats van in het systeemvak. Handig om te testen.
VensterToont het adres dat je op de telefoon invult. Laat het venster openstaan.
StoppenDruk in dat venster op Ctrl+C.

7. Sneltoetsen

Ctrl + CServer stoppen (alleen in de console-versie)

8. Updates

Bij het opstarten kijkt de app stil of er een nieuwe versie is. Alleen als dat zo is, krijg je een melding met een knop Downloaden. Er gaat niets van jou mee, en zonder internet merk je er niets van.

Wil je dat niet? Zet in de melding het vinkje Niet meer automatisch controleren aan.

9. Tips

  • Telefoon en pc moeten op hetzelfde wifi-netwerk zitten.
  • Het model zit niet in de EXE; de server gebruikt het model uit de map DraveKITT.
  • Staat DraveKITT ergens anders? Zet het pad in een bestand dravekitt_path.txt naast het programma.
  • Vragen over het weer ('wat is het weer in ...') haalt de server live op, zonder sleutel.
  • Heb je op de server een wachtwoord ingesteld? Vul hetzelfde wachtwoord dan in bij de telefoon-app (Instellen).

10. Als iets niet werkt

De telefoon vindt het hoofdkwartier nietControleer of het drakenicoon er is en of telefoon en pc op hetzelfde wifi zitten. Sta de server toe in Windows Firewall.
KITT zegt 'Mijn systemen starten nog op'Het model wordt nog geladen. Wacht even tot het adres in het menu staat.
Er komt geen echt antwoord, of de status meldt dat het model niet beschikbaar isStart de pc-app DraveKITT en download daar eerst het taalmodel.
Windows zegt 'Windows heeft uw pc beschermd'Klik op 'Meer informatie' en dan op 'Toch uitvoeren'.

11. Waar staan mijn gegevens?

De server gebruikt de map DraveKITT-data in je DraveKITT-map: daar staan de instellingen (config.json), het taalmodel en het geheugen van KITT.
