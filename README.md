# KITT-Server

Jouw persoonlijke "hoofdkwartier" voor DraveKITT Mobile.

> 🔗 **Hoort bij elkaar:** KITT-Server is de **motor** op je pc (het denkwerk). [DraveKITT Mobile](https://github.com/mbrv4ever/DraveKITTMobile) is de app op je **telefoon** (praten en luisteren). Je hebt ze **allebei** nodig.

*Categorie: Web en servers · versie 1.0.3*

## ⬇️ Downloaden (Windows, geen Python nodig)

### [👉 Download KITT-Server 1.0.3](https://github.com/mbrv4ever/KITT-Server/releases/latest)

1. Klik op de link en download het **.zip**-bestand.
2. Pak het uit: rechtsklik → **Alles uitpakken...**
3. Dubbelklik op **KITT-Server.exe**.

> Zie je een blauw scherm "Windows heeft uw pc beschermd"? Klik op **Meer informatie** → **Toch uitvoeren**.

## Vanaf de broncode

Installeer Python 3.10 – 3.13 en de benodigde pakketten (zie `requirements.txt` als die er is), en start het hoofdbestand (`.py`). Eventuele `.bat`-bestanden doen dit voor je.
